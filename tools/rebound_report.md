# 短线「超跌 → 企稳 → 放量反弹」回测(对比标普 500)

形态:前面大跌(离 120 日高点回撤 ≥ dd)→ 最低点之后不再创新低 → 一波反弹(放量)→ 缩量回调,回调低点高于前低 → 今天重新上涨且放量。**「庄家控盘」无法直接测,用成交量形态当代理。**

入场 T+1 开盘价,持有 1、3、5、10、30、60、120 天,成本每边 0.10%。样本内 = 2023 年以前,样本外 = 2023 年以后。**偏差:** 幸存者偏差(没有退市股,对「买大跌股」影响最大)、用当时估计市值(今天市值×当时价格/今天价格)筛选 ≥ 50 亿。

全部候选事件(宽松阈值,当时估计市值 ≥ 50 亿):52,932 个(样本内 26,122,样本外 26,810),同一只股票 10 天内不重复。
