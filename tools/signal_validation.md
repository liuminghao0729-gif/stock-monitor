# 搜索到的组合的严格验证

对 30、60、120 天持有期各搜索到的组合(只用样本内选出)做:分年份、阈值邻域(只动一个阈值)、个股集中度、全体股票(含不活跃的一半)、等权组合曲线(含 beta/alpha、最大回撤)。成本每边 0.10%。

**偏差(会让数字偏好看):** 幸存者偏差(没有退市股)、今天的市值筛选;样本外 2023 年起基本是牛市,且是少数赢家股票领涨的行情。
