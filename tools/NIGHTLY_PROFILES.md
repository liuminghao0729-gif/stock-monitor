# 每晚写「通俗解读」的任务说明(给定时运行的 Claude 看)

目标:给标普 500 里还没有解读的公司,按市值从大到小,每晚写 **20 家**,写进 `public/profiles_gen.json`。

## 步骤
1. `python3 tools/profile_queue.py --next 20` 看今晚要写哪 20 家(已经写过的会自动跳过)。队列文件 `tools/profile_queue.json` 若超过 30 天没更新,先运行 `python3 tools/profile_queue.py` 刷新。
2. 对每一家:
   - `SEC_CONTACT=<联系邮箱> python3 tools/profile_data.py 代码` 取素材:年报业务描述、收入构成、TTM 财务、在手订单(SEC 数据)。
   - 用网络搜索补两三条**最近的、可核实的**信息:最近一季财报要点、主要客户或竞争对手、管理层对订单/需求的说法、最近的重大风险。优先官方来源(公司财报、SEC、投资者关系页面),其次是主流财经媒体。
3. 按下面的格式,把这一家写进 `public/profiles_gen.json`(保留文件里已有的所有条目,只新增)。
4. 全部写完运行 `python3 tools/validate_profiles.py`,必须显示「全部通过」。不通过就修好再继续。
5. 只提交 `public/profiles_gen.json`(和刷新过的 `tools/profile_queue.json`),不要改任何其他文件。提交信息:`通俗解读(夜间):<日期> <代码列表>`,然后推送到 main。

## 每条的格式(和页面上手写的苹果、英伟达一致)
```json
"代码": {
  "one": "一句话说清这家公司做什么、怎么赚钱(80 字内,不用术语)",
  "money": ["靠什么赚钱 1:一句话", "靠什么赚钱 2"],            // 2 到 4 条,占比大的在前
  "strong": "强在哪(护城河):为什么对手难抢走生意",
  "choke": "产业链位置或卡脖子:它在行业链条的哪一环,上下游依赖谁",
  "orders": "订单线索:有公开披露的订单/剩余履约义务/长期协议就写;消费品没有订单就写看什么指标。订单不等于收入",
  "risk": ["反方或风险 1", "风险 2", "风险 3"],               // 3 到 4 条,第一条写最有力的反方观点
  "watch": "接下来盯什么:2 到 3 个具体指标",
  "grade": "A",                                            // A=资料充足;B=资料有限或历史短;C=资料很少
  "note": "一句提醒(周期股、刚上市、业务复杂等)",
  "date": "YYYY-MM-DD",                                    // 写作日期
  "by": "night"
}
```

## 写作规则(必须遵守)
- 对象是**完全不懂行的人**:一句话讲清,术语第一次出现要解释(例如「HBM:贴在 AI 芯片旁的高速内存」)。
- **不写任何没有来源的数字。** 页面上已经会自动显示营收、利润、毛利率等 SEC 数字,所以文字里只在说明含义时引用素材脚本里打印出来的数字;网络上查到但没核实原文的数字,必须加「(公司说法,未核实原文)」或「(外部资料,未核实)」。
- 订单不等于收入;长期协议不等于已确认收入;管理层说法要标明是说法。
- 资料不够就写「资料不足」,不要编。找不到的东西不等于不存在。
- **不给买卖建议、不给目标价、不预测股价。** 只解释公司是什么、怎么赚钱、风险在哪。
- 风险部分第一条必须是最有力的反方观点。
- 中小公司或刚上市/刚分拆的公司,grade 写 B,并在 note 里说明原因。
- 同一家公司的不同股份类别(如 GOOG 和 GOOGL)只写一份,用主代码。
- 如果某家公司的素材取不到(SEC 查不到、外国公司等),可以只用年报业务描述和网络搜索写,grade 写 B 或 C,并在 note 说明。
- 今晚时间不够写完 20 家也没关系,宁可少写,不要凑数;写不完的明晚接着写。
