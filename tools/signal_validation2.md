# 去偏差检验:当时的估计市值筛选 + 同 beta 杠杆标普对照

**(1) 估计市值筛选:** 估计市值 = 今天市值 × 当时股价 / 今天股价(假设股本不变,是粗略估计)。只保留「当时估计市值 ≥ 50 亿 / 100 亿美元」的观测,去掉那些「今天才成为大公司的小公司」。

**(2) 杠杆标普对照:** 组合的 beta 如果是 1.8,就拿 1.8 倍的标普(每天再平衡,不计融资成本)对比——看组合的收益是不是只是杠杆。
